# 本地网页工作流

不熟悉命令行的 macOS 用户可使用 [桌面预览](desktop-preview.md)，应用自带运行环境，
共用下述学习、材料、模型同意和进度保存逻辑。其余平台仍使用 Python 启动网页。

学生只需要打开网页、选择学科和课程材料，再点击“生成我的自学讲义”。
已有讲义打开后，材料导入区自动收起。点击知识点会直接滚动到讲解，
翻到下一页不会代替学生标记“完成”。

## 生成与失败恢复

- 上传验证通过后，文件复制到本地独立任务目录；同名文件不会覆盖前一次导入。
- 页面显示材料处理、录音转写（如有）、配对、讲义组织、检查和保存阶段，不估算虚假的百分比。
- 刷新或关闭浏览器不取消服务中的任务。重新打开网页会读取最近一次任务。
- 关闭本地服务会中断未完成的任务；重新启动后可以使用已保存材料从头重试。
  录音按份复用已完成转写，重试时不重新发送已完成录音。渲染阶段仍从头执行，单份录音不支持中途续传。
- 全部输入均不可读时，任务失败并保留旧讲义。部分文件可读时，草稿报告列明未读取的文件。
- 讲义、来源地图、生成报告和三种导出全部保存后，才切换当前讲义。
  “任务成功”表示文件已保存；“教学草稿”仍表示内容不完整。
- 老项目不需要迁移；没有新任务指针时，继续读取原来的 `derived/`。
  `study export`、`study validate --project`、`study generate` 等命令可解析当前网页课程。
- 已打开的任务结果、图片和下载指向同一次生成，不随另一窗口更换材料而混用。

## 补充转写或替换坏文件

生成后，导入区逐文件显示读取结果：读取到多少文字页或转写片段、多少段有起止时间、
多少段页面关系待确认；录音尚未转写、文件打不开和无文字页面分别说明下一步操作。
这些是材料处理结果，不是课程完成度。图表与公式即使提取到了文字，也仍需核对。

1. 在草稿提示中点击“查看材料处理结果”，或展开材料导入区。
2. 保持“补充或修复这次材料”，勾选要继续使用的文件，只添加缺失的教师转写。
   替换某个文件时，取消勾选旧文件，再添加新版本；同名文件不会被静默替换。
3. 点击“用保留和新增的材料重新生成”。旧文件和上一版讲义保留；本次失败时仍可读旧版。

文件可以分多次选择或拖入，生成前也可移除误选项。保留与新增文件合计最多 60 个、100 MB。
刷新页面后可以直接使用已保存的文件，不必重新上传；尚未点击生成的文件选择不会保存。
补充流程继承本课身份，只保留内容未改变单元的有效学习记录。若要导入另一门课或另一课次，
选择“开始另一节课”，原课程的文件不加入此次生成。

补材料默认使用本地离线生成器，也可在本次生成时主动选择模型；它不能让任意课程自动变为完整教材。
没有足够解释、例题、来源或可核实的教师观点时，结果继续显示为草稿。

## 对照原页与离线导出

讲解的“材料中看什么”提供可收起的原页预览、前后页和放大入口，保留原文件的真实页码。
原页不会因第 2 页读取失败而把第 3 页标成第 2 页。预览区域保留固定空间，避免慢加载打乱阅读位置。
逐文件结果也可展开预览；扫描件导致本次生成失败时，已渲染的页面仍可看，旧课不会被替换。

桌面应用自带 PDFium/Pillow；开发环境可安装 `.[pdf]`。缺少可选组件时可回退到本机 Poppler。
PPT 仍需要本机 LibreOffice 转成 PDF；缺少工具时保留文字结果并提示，或由学生另存 PDF 后导入。
图像渲染在本机独立进程完成，每文件最多 200 页、160 MiB，总计最多 500 页、256 MiB，
单页最长边 2400 像素、约 400 万像素，单个渲染任务限时 90 秒；超过限制会说明缺口。
原文件保持不变；应用关闭后渲染子进程也会退出。文字抽取和图示理解是分别报告的状态；没有自动 OCR。

HTML 导出会内嵌原页，可独立离线阅读，复习答案保持折叠。同一图像只嵌入一次；单张最多 32 MiB、
合计原始图像最多 256 MiB，Base64 编码后文件会更大。缺图、损坏或超限有明确提示。
只读取本课程 `derived/rendered/` 内的 PNG/JPEG/WebP，拒绝通向课程外部的符号链接。
Markdown/JSON 保留相对图像路径，单独移动这些文件不会携带图片。网页的文本模型流程仍只发送明确同意的文字，
新增本地预览不会自动发送图像或调用视觉模型。

## 在网页中转写录音

已转写且有真实时间标记的录音，可以在教师补充旁点“听这一段”，支持倍速与重听，
有明确段尾时自动暂停；切换知识点或关闭回听会释放播放器，不影响作答草稿。
未配对片段仅在来源附录提供回听并保留待确认标签。纯转写文件没有对应录音时不显示按钮，
不会按文件名猜测关联；缺少真实起始时间时也不从录音开头冒充定位。
回听只读取本机原录音，不重复转写、不上传。原录音改变后拒绝沿用旧时间段。
下载讲义只携带文字和已生成原页，不附带录音或临时播放地址。

1. 添加录音，或保留之前已导入的录音；出现“录音怎么处理？”后选择“转写所选录音”。
2. 输入转写密钥，核对所列录音及发送地址。默认用 `whisper-1` 请求分段时间戳；
   要用兼容接口或其他模型，可展开“调整转写服务或模型”。
3. 单独确认录音发送范围，再生成。转写服务只收到所列录音，不收到课件、笔记或其他任务文件。

默认“只用本机已保存的转写”不会创建转写连接，也不读取环境密钥。
补材料时，仅继承勾选保留录音的有效转写，按文件校验和重新对应来源；
取消勾选的录音和转写不加入此次生成，旧记录仍保留在原任务中。
后续录音失败时，前面的结果留在本机；重试需要重新确认服务与发送范围，或主动改成本机模式。
本机模式可先恢复已有部分，剩余录音会报告为尚未转写。多份不同本地转写不会被自动合并，需明确选择原服务和模型。

转写结果没有时间戳时只保留为待定位文字；未知页配对仍待确认，不能自动变成教师已核实观点。
本工具每段上传上限为 24 MB，整批在请求前检查。回复上限为 4 MB，超限或格式错误不会使用截断结果。
服务错误后立即停止，不自动重试或跟随重定向；相同服务地址、模型和请求格式才复用转写缓存。
网页使用标准库 HTTP 连接，桌面包不需要安装语音 SDK。本文涉及的服务兼容性用本机合成服务验证，
尚未完成真实付费转写、识别准确率或正确课次配对验收。

## 在网页中使用模型讲解

1. 在“怎样生成这节课？”中选择“模型讲解”，选择模型服务。
2. 填写该服务的模型名称与 API 密钥。OpenAI 使用固定官方地址；其他兼容服务需填写基础地址，
   例如 `https://api.example.com/v1`。本机模型可使用 HTTP，无认证时可留空密钥。
3. 核对发送地址、所选文件和文字范围，再勾选同意，点击生成。

发送内容包括本次文件提取的课程文字、页码、可配准的教师片段和必要教学上下文，
这个讲解连接不发送原始录音、页面图像或其他任务的文件；录音上传由上方转写设置单独确认。
未配准的转写正文不进入模型上下文。
模型先提出整课规划，再逐知识点生成讲解；模型提出的知识依赖仍属于待复核的导师建议。

每次生成都要主动选择；更换材料、地址或模型后需要重新确认。
密钥只保留在浏览器表单和当前服务进程内存中；提交后清空表单，任务结束后释放服务端引用。
不会写入浏览器存储、任务记录、项目文件或导出结果，也不会使用服务器环境中的密钥。
刷新后恢复的是任务状态，不恢复密钥、不自动调用。模型服务可能按请求收费，应用不作费用估算。

模型调用不自动重试；连接、权限或服务错误后停止后续请求。每次最多 61 次请求（一次规划及最多 60 次讲解），
单次请求正文和回复各最多 2 MB，过大时拒绝而不截断。没有任何知识点通过现有教学完整性检查时，
任务失败并保留旧讲义；临时草稿仍在本次本机任务目录中。有部分通过时，可以保存明确标注缺口的草稿。
这些检查不代表专家核验了答案。重试模型任务须重新填写并确认，或主动改选本地草稿。

网页模型连接使用 Python 标准库，OpenAI 走 Responses，兼容服务走 Chat Completions。
远程地址要求 HTTPS，不接受地址内的账户、查询参数或密钥；不会跟随重定向发送材料和凭据。
请求设置 `store: false`；服务商自身的保留政策仍需单独查看。
接口用法依据 [OpenAI 文字生成文档](https://developers.openai.com/api/docs/guides/text)
和 [Responses 迁移文档](https://developers.openai.com/api/docs/guides/migrate-to-responses)。

## 学习记录

阅读位置、完成标记和练习草稿自动保存到浏览器，同时尝试写入课程工作区。
本地服务重启或换用端口后，可以从工作区恢复。答案始终默认折叠，
已写的草稿不会因为打开标准答案而被替换。

记录按课程材料和单元内容区分。同名课程不会仅凭标题共用记录；
修订后的单元会清除其过时完成状态和练习草稿，未变动单元保留进度。
旧版按标题保存的完成数组仍留在浏览器，但不会自动导入，以免误用另一门同名课程的记录。

多窗口同时更新会拒绝过时版本覆盖，提示冲突；各窗口草稿仍保存在自身浏览器中。
目前没有多设备同步，也不自动合并多窗口答案。不要将“本机保存”等同于云备份。
直接打开讲义 JSON 时，也可以使用浏览器保存记录；该文件中的相对截图不自动关联当前服务的另一门课程。

## 本地文件与接口

工作区包括：

```text
.study-state.json                         当前已保存讲义的指针
.study-jobs/<任务>/job.json                阶段与状态
.study-jobs/<任务>/workspace/sources/      上传材料的本地副本
.study-jobs/<任务>/workspace/derived/      来源地图、讲义和报告
.study-jobs/<任务>/workspace/exports/      Markdown、HTML、JSON
.study-progress/<课程哈希>.json            本机学习记录
```

这些目录均由 Git 忽略。默认绑定 `127.0.0.1`；接口验证 Host 和写入 Origin，
图片只提供课程渲染目录中的文件，不提供任意原文件路径。课程工作区不具备用户登录或权限隔离，
它适用于个人电脑的本地服务。

开发接口：

| 操作 | 接口 |
| --- | --- |
| 新建任务 | `POST /api/jobs`，返回 `202` 和任务记录 |
| 查询/刷新任务 | `GET /api/jobs/latest`、`GET /api/jobs/<id>` |
| 重试 | `POST /api/jobs/<id>/retry` |
| 补充/替换保存的材料 | `POST /api/jobs/<id>/revise`，`keep` 为本次保留的 `stored_name` 列表，`files` 为新增上传列表 |
| 读取该次结果 | `GET /api/jobs/<id>/guide` |
| 当前讲义和来源地图 | `GET /study-guide.json`、`GET /lesson-map.json` |
| 下载 | `GET /api/exports/md`、`html`、`json`；可用 `?run=<id>` 指定已完成任务 |
| 学习记录 | `GET/POST /api/progress/<课程哈希>`；写入需匹配版本 |

原型中的 `/api/generate` 保留为异步提交别名，响应改为 `202 {job: ...}`。
集成方应轮询任务并在成功后读取结果。
新建、补充和重试接口可显式携带 `generation`：`provider`（`none` / `openai` / `compatible`）、
`model`、`base_url`、`api_key` 与布尔值 `consent: true`。不提供时始终为本地模式；模型重试不能沿用上次密钥或同意。
持久化的 `generation` 仅记录非秘密设置和请求/教学完整性检查计数，不含密钥或响应原文。
`speech` 使用相同的设置字段，但必须独立明确确认，范围为所选录音。省略或 `provider: none`
表示只读本机已有转写；不会沿用上次网络调用授权。其 `stats` 记录请求次数、有效返回、片段数及复用录音数，
不表示识别准确率。`retained_sources` 仅记录所保留文件的新旧标识，用于把原本地转写对应到新来源。
其中 `requests` 是调用尝试数（包括发送前拒绝），`succeeded` 是收到完整文字回复的次数，
`checked_units` 是通过现有单元内容检查的数量；这些都不是答案正确率。
任务记录的 `materials` 包含逐文件读取状态及补齐建议；`parent_job_id` 表示补充所依据的上次记录。
其中 `rendered_page_count`、`preview_pages` 和 `preview_notes` 分别记录预览数、真实页码/图像相对路径和预览缺口。
任务图片接口允许读取成功、失败或已中断任务的渲染页，讲义和导出仍只发布成功结果。
补充接口只接受该任务已保存文件的标识，不接受任意本地路径。文件保留顺序沿用原记录，新增文件排在最后。

## 工程验证

Python 测试覆盖导入隔离、失败保留、重试、并发拒绝、服务独占、启动恢复、
发布前后写入失败、接口边界、进度冲突及旧 CLI 导出。
Node 测试覆盖课程隔离、序列化恢复和修订失效。
Playwright 使用真实本地服务，分别检查桌面、390px 和 320px 手机视口下的阅读、练习、
答案折叠、导航、无整页横向溢出和上传失败恢复；它不能代替实际手机与学生盲测。

安装包检查必须在源码目录外运行：

```bash
python -m pip install build
python -m build --wheel
python -m venv /tmp/mst-wheel-check
/tmp/mst-wheel-check/bin/python -m pip install --no-deps dist/*.whl
cd /tmp
# 将下面路径换为本仓库的绝对路径
/tmp/mst-wheel-check/bin/python /path/to/repository/tests/check_installed_web.py
/tmp/mst-wheel-check/bin/python -m pip install 'multimodal-study-tutor[pdf]'
/tmp/mst-wheel-check/bin/python /path/to/repository/tests/check_installed_pdf.py
```

网页文件随 wheel 发布，运行时不再依赖原仓库里的 `web/` 目录。
macOS 本地浏览器检查可设置 `CHROME_PATH` 使用已安装的 Chrome；CI 使用 Playwright Chromium。
上述检查验证操作和文件可靠性，不证明解释、例题答案或知识依赖已经教学正确。
