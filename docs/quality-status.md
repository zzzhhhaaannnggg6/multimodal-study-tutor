# 当前质量状态

目标是让没有听课的大学生靠讲义完成理解、做题和纠错。自动检查证明的是一些处理规则可以工作，不能代替学生独立学习验收；本版本不宣称各项体验已达到 8 分。

## 本轮可检查的改进

| 学生遇到的问题 | 当前行为 | 验证方式 |
| --- | --- | --- |
| 时间标记被当成教师讲解 | 合并 DOCX 时间标记与后续讲话，原段落位置保留在后台；空时间段不成为引文 | 分段、重复标记、时间重置和无结束时间测试 |
| 不同课次讲解混进同一份讲义 | 仅使用源文字锚点；忽略生成说明、页码和裸数字；弱配对留待确认 | 同分候选、双语术语、不同课次合成样例与本地真实材料检查 |
| 读图时把普通连接理解为单向流程 | 连通关系与箭头方向分开；处理双向、旋转、翻转和嵌套组坐标 | 人工检查实际渲染页，并测试不同箭头类型和组坐标 |
| 公式的指数消失，指令只剩术语 | 保留明确的上下标；说明实际源/目标操作数、地址、结果写入和 PC 条件 | 带格式的合成 PPTX、完整算式和访存/分支指令测试 |
| 模型几句概括被凑成完整教材 | 不再补通用步骤或练习角色；教师摘录、理解权重和评价信号不接受模型覆盖 | 不完整模型回答、无依据考试承诺、完整来源传递测试 |
| 有例题却不会独立做下一题 | 已识别的基础指令示例提供直白解析、先修知识、逐步追踪、易混对照及三个具体练习 | 改变输入后重新计算，并检查读取与写回的区别 |
| 导出后无法查未配准来源 | Markdown/HTML 包含折叠来源索引；HTML 复习答案能回到讲解 | 导出与回跳检查 |

本地端到端检查使用一份 61 页课件和另一课次的 DOCX 转写。转写被还原为 779 个片段，79 个属于导出信息、课堂事务或无教学内容的片段；其余 700 个保留为配对待确认，没有写入本课教师讲解。这个结果证明该组不匹配材料没有被强行合并，不能用来证明正确课次的对齐准确率。

原文件、教师信息、转写原文、页面截图和本地生成结果均不进入公开仓库。本轮没有调用云端模型。

## 尚未达到的学习要求

- 没有知识单元地图时，仍按相邻页面临时分组，尚未可靠恢复跨页知识依赖。
- 除部分计算机系统材料模式外，离线讲解仍包含通用框架；新增学科 profile 只是术语与学习动作配置，不代表已验证的学科教学能力。
- 文字匹配和整份转写支持率都是启发式规则，会漏掉意译、转写错误和跳页讲述；当前没有可靠的课堂顺序模型，也没有配对准确率基准。
- 图形关系始终是待复核线索；缺失变换、曲线连接、截图和靠空间排布表达的公式仍需要进一步处理。明确的上下标可以保留，不能仅凭字体大小推断数学含义。
- 指令解析不是汇编器或通用执行器，尚未完整验证立即数范围、扩展集与所有语法。`muli` 不属于标准 RISC-V；教学记法的实际编码不能直接假定为一条 32 位指令。
- 没有完成面向大学生的盲测，不能据结构检查声称学生已经可以完全独立学习。

下一轮优先验证正确课次的配对、恢复知识依赖，并把仍是通用框架的单元改成有具体推理、完整例题和可独立作答练习的讲解。免安装入口和更多学科的专用解释仍待进一步开发。

## 工程与学习操作改进

本地网页已加入独立任务、刷新恢复、失败重试、保存完成后切换当前讲义，以及本机学习记录。
损坏输入不会用空洞“成功草稿”替换已有课程；部分文件读取失败时会进入讲义报告。
网页现在读取正确的 `generation_report` 字段，展示真实的草稿与待确认状态。

阅读位置、完成标记和练习草稿分开记录。翻页不自动算完成，答案默认折叠；
课程内容修订会使对应旧记录失效，另一个窗口的新记录不会被静默覆盖。
手机视口下的点击区域、自动滚动、练习输入、横向溢出及恢复流程已进入浏览器测试。
截图也进行了人工查看，但尚未在真实手机和不同浏览器上完成完整验收。

macOS 双击入口直接打开网页，不要求先选文件夹或重复生成旧课。
wheel 安装包包含网页文件，并在独立环境、源码目录外检查过启动。
它仍依赖 Python 3.10+；没有因此成为免安装应用。

详细验证和已知限制见 [本地网页工作流](local-web.md)。
这些改进提高操作可靠性，没有解决前述知识依赖、任意课程讲解质量和教学正确性验收缺口。
