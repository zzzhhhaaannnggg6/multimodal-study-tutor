# 当前质量状态

目标是让没有听课的大学生靠讲义完成理解、做题和纠错。自动检查证明的是一些处理规则可以工作，不能代替学生独立学习验收；本版本不宣称各项体验已达到 8 分。

本地端到端检查使用一份 61 页课件和另一课次的 DOCX 转写。转写被还原为 779 个片段，79 个属于导出信息、课堂事务或无教学内容的片段；其余 700 个保留为配对待确认，没有写入本课教师讲解。这个结果证明该组不匹配材料没有被强行合并，不能用来证明正确课次的对齐准确率。

原文件、教师信息、转写原文、页面截图和本地生成结果均不进入公开仓库。本轮没有调用云端模型。

同一组真实本地材料已用新规划流程重新检查：离线标题合并得到 52 个主题单元，840 个页面/语音来源记录全部保留，700 个待配对片段仍未进入教师讲解。52 个主题不等于已恢复课程知识结构；主线显示“待梳理”，结果保持草稿，严格讲义检查仍不通过。

模型规划测试使用确定性的合成回答，没有进行真实模型效果基准。规划通过来源和图结构检查后仍标为“导师建议、教学合理性待复核”，不会因此变成已核验课程。

数值正确性评测现有三份共 110 个公开合成案例，检查实际例题、回忆题、过程题、迁移题及来源边界；
数制参考计算使用位权和几何级数，与生成器的余数法分开。二进制加减法用低位前缀核对逐列递推，
包括连续进借位和最高进位。循环小数、负数、精度边界及条件不足均有检查。
这是有限题型的数值证据，不是整门课程的正确率，也不是学生或专家验收。运行方式见 [教学正确性评测](evaluation.md)。

## 尚未达到的学习要求

- 没有知识单元地图或模型时，仅在同一份材料内合并相同明确标题及续页，不猜测知识依赖。明确选择模型后可提出整课规划，但摘录与依赖图检查不能证明分组、先修理由或教学顺序正确；任意课程的可靠规划仍未完成。
- 除明确的数制转换、普通二进制加减法和部分计算机系统材料模式外，离线单元现在只整理材料，不再把通用学习动作充作讲解和练习；这些单元仍不能支持独立学习。已识别但缺少具体练习的模式保留讲解并报告缺口，不再自动凑题。学科 profile 本身只是术语与学习动作配置，不代表已验证的学科教学能力。
- 文字匹配和整份转写支持率都是启发式规则，会漏掉意译、转写错误和跳页讲述；当前没有可靠的课堂顺序模型，也没有配对准确率基准。
- 图形关系始终是待复核线索；缺失变换、曲线连接、截图和靠空间排布表达的公式仍需要进一步处理。明确的上下标可以保留，不能仅凭字体大小推断数学含义。
- 指令解析不是汇编器或通用执行器，尚未完整验证立即数范围、扩展集与所有语法。`muli` 不属于标准 RISC-V；教学记法的实际编码不能直接假定为一条 32 位指令。
- 没有完成面向大学生的盲测，不能据结构检查声称学生已经可以完全独立学习。
- 内容规则能发现特定空洞或重复写法，数值核对只覆盖明确识别的位置记数法转换和普通二进制加减法；补码、固定字长与负差仍需另行处理。不能证明任意推理或答案正确，不能检测所有改写后的套话。专家审阅、学生盲测及更广的正确性评测仍缺失。

后续重点是验证正确课次的配对和模型提出的知识依赖，并把仍是通用框架的单元改成有具体推理、完整例题和可独立作答练习的讲解。桌面预览已有独立构建，正式免安装发行和更多学科的专用解释仍待完善。

## 工程与学习操作改进

本地网页已加入独立任务、刷新恢复、失败重试、保存完成后切换当前讲义，以及本机学习记录。
损坏输入不会用空洞“成功草稿”替换已有课程；部分文件读取失败时会进入讲义报告。
网页现在读取正确的 `generation_report` 字段，展示真实的草稿与待确认状态。
逐文件读取结果区分文字读取、无文字页、坏文件和未转写录音，并给出补齐入口。
学生可沿用已保存的课件补交转写，或替换单个文件；补充生成沿用课程身份，
新版本失败时原讲义仍可用。这仍不能证明材料被正确讲解或全部知识已覆盖。
网页可主动选择文本模型，沿用整课规划和逐单元精讲流程；默认仍为本地草稿。
本机模拟 API 验证了显式同意、所选文件范围、错误后停止请求、密钥不持久化和模型回答缺失时保留旧讲义。
尚未用真实付费服务完成端到端验收，也没有因此证明任意模型或兼容服务都能稳定生成正确课程。

网页现已接入独立确认的录音转写，默认不上传。转写和讲解的密钥、地址与同意分别管理，
两种连接都不读取环境密钥。页面显示转写进度与实际片段/时间计数；没有时间戳只保留为待定位。
补材料仅复制所保留录音的有效本地结果，来源编号变化不会触发重新上传。
后续失败保留前面已完成结果，重试时需要新的服务选择；可选择本机模式先恢复有效部分。
同一录音存在不同本地转写时不自动合并，需要明确原服务和模型；损坏缓存不会触发付费重转。
转写 HTTP 请求、浏览器、独立 wheel 及原生应用流程使用合成服务验证，未调用真实录音或云端转写。

阅读位置、完成标记和练习草稿分开记录。翻页不自动算完成，答案默认折叠；
课程内容修订会使对应旧记录失效，另一个窗口的新记录不会被静默覆盖。
手机视口下的点击区域、自动滚动、练习输入、横向溢出及恢复流程已进入浏览器测试。
截图也进行了人工查看，但尚未在真实手机和不同浏览器上完成完整验收。

macOS 双击入口直接打开网页，不要求先选文件夹或重复生成旧课。
wheel 安装包包含网页文件，并在独立环境、源码目录外检查过启动。
脚本与 wheel 入口仍依赖 Python 3.10+。

独立 macOS 预览现使用原生窗口和内置 Python 后端，学生运行应用时不需要 Python 或命令行。
本机实际构建要求 Apple 芯片、macOS 26.0+；签名只有 ad-hoc，尚未完成 Apple 公证。
原生 WKWebView 合成流程已检查导入 Markdown/PDF、真实 PDF 文字提取、三种导出、作答、退出与移动应用后重开；
原生下载委托还检查了重复覆盖同一个 Markdown 导出文件；下载完成前保留旧文件。
课程、答案和完成标记恢复，后端随应用结束。关闭窗口会等待正在保存的最新作答，
刚进入精讲便退出也会记录新阅读位置；保存冲突不会被报告为成功。
冻结运行时检查找到 120 个证书根，TLS 证书和主机名验证保持开启。
本轮没有调用云端模型，也没有操作系统文件选择框/保存框的自动化验收、跨版本兼容或真实学生测试。
这些结果证明本机预览可运行，不代表正式桌面发行完成。详情见 [桌面预览](desktop-preview.md)。

转写服务不能自行把页面配对标成“已复核”。新增片段会重新执行本地配对，保留原时间及录音来源。
已完成录音默认复用本地转写，不重复调用服务；后续录音失败会保留前面成功的转写，但来源地图保持整批更新。
明确重新转写时，内容或时间变化、片段减少都会报错，不静默替换已有来源。空结果、空段和无效时间不保存为成功。
上传使用经文件校验的临时本地副本；原录音在导入后被替换，整批会在调用服务前停止。
缓存损坏不会触发自动付费请求。单份录音内部续传、并发 CLI 去重和服务端请求成功但本地尚未保存便崩溃的恢复仍未实现。
