# 教学正确性评测

结构齐全不代表答案正确。本版本开始用可重复的数值题检查实际讲义输出，
同时保留专家审阅与学生独立学习验收的缺口。

## 当前证据范围

`evals/number-conversion-v1.json` 是公开的合成题库，共 31 个案例：

- 21 个求解案例：二、八、十、十六进制之间的转换，包含小数、负数、零、
  前导零、不同进制标记、循环小数以及超过二进制浮点精度的整数。
- 2 个材料冲突案例：材料答案与按位权计算的结果不一致时，保留双方，标为待确认。
- 8 个保留草稿案例：缺少数值、数字非法、多个题目混杂、补码解释不明，或展开超出当前范围。

案例输入和目标答案固定在题库中，评测读取生成的实际题目、例题答案、回忆题、过程题、
迁移题以及来源记录。生成器使用整数除法和余数循环；答案读取器使用位权和几何级数，
按精确分数比较，避免用生成器自己的输出充当标准答案。
另外对多个分子、分母和进制组合检查精确数值保持，并用故意改错答案的测试确认评测会失败。

当前只支持上述位置记数法。它不是通用公式求解器，不会验证任意自然语言推理、
证明、史料解释、指令执行或教师观点。答案需要按约定的带进制写法才能被自动核对；
不能读取的写法会留待复核，不能据此判定学生或模型回答必然错误。
详细解释中的每句话、图示含义和学习顺序仍需要独立审阅。

## 运行与复查

在仓库中安装项目后运行：

```bash
study evaluate evals/number-conversion-v1.json \
  --save-guides local-data/evaluation/candidates \
  --output local-data/evaluation/report.json
```

默认只使用本地离线生成器，不调用模型，也不读取私人课程。报告包含题库版本、
题库哈希、候选讲义哈希、通过数量和逐题失败项；不输出候选讲义原文。
生成的合成讲义可以逐份导出或打开，人工核对过程是否足以让学生学会。

检查已经生成的候选讲义：

```bash
study evaluate evals/number-conversion-v1.json \
  --guides-dir local-data/evaluation/candidates \
  --output local-data/evaluation/recheck.json
```

目录中的文件名须为 `<case_id>.json`。候选讲义应由 `mst.evaluation.case_map(case)`
构建的合成来源生成，保留题目、课程 ID 和原始来源记录。可以在独立脚本中明确选择
自己的模型 provider 后生成候选；评测命令本身不提供云端上传开关。
缺失候选、来源变化、错误答案、错误迁移结果或未保留冲突都会失败。

退出码为：0 表示这份题库全部通过，1 表示至少一个案例失败，2 表示题库无效。
GitHub Actions 在 Python 3.11 和 3.12 上运行同一题库，并保存合成评测报告。

## 生成时的边界

明确识别数制转换后，程序按原数计算，不再看到 `635` 就补成固定例题 `635.177`。
例题展示位权、整数除法和小数乘法的实际数值，并给出有确定答案的变式。
循环小数会标出循环节，超过当前 64 位小数展示范围的题目不会被截断后称为精确答案。
来源数字最长 48 个字符；无法明确确定原数、原进制或目标进制时，不生成完整数值例题。
补码和固定字长不按普通位置记数法猜解。

生成流程和严格讲义验证会核对明确识别的数制例题、过程题及既定迁移题答案。
模型改变原题、算错、改动既定练习条件或返回无法读取的数值写法时，讲义保留为草稿。
材料与计算冲突时，原文、计算结果和待确认状态均保留，模型不能抹去这一对照。
这项检查与现有的重复解释、空洞步骤和来源验证互补。

## 尚未完成的验收

31 个合成案例通过，证明当前版本在这些边界上的行为可重复，不能换算成任意课程的正确率或体验分数。
尚未完成领域专家审阅、大学生盲测、正确课次对齐基准、任意模型的真实生成评测，
也没有因此达到稳定公开发布或完全独立学习的标准。
