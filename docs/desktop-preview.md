# 听课助手桌面预览

学生双击应用就进入学习页面，不需要安装 Python、复制命令或手动维护本地服务。
课程处理和模型同意流程与网页版本共用。它是可运行的本地预览，尚未完成正式桌面发行。

## 学生怎么用

1. 解压与你的 Mac 芯片和系统版本相符的预览包，打开「听课助手.app」。
2. 添加课件和教师转写，选择学科。默认生成本地草稿；需要模型讲解时，展开设置并确认本次发送范围。
3. 从学习路线开始，看讲解、做练习。退出后再次打开，会恢复当前讲义和已保存的阅读位置、完成标记、答案草稿。

应用带有自己的运行环境、PDF 文字读取器和原页渲染器。未选择模型时，不发起云端教学请求。
本地草稿仍可能缺少讲解，不应当成完整课程。录音默认不上传；可在“录音怎么处理？”单独选择并确认转写。
仅有图片的扫描 PDF 不会自动 OCR。
PDF 图表、公式和排版可在讲解旁直接对照，支持翻页和放大；扫描页也可在材料处理结果中预览。
导出的 HTML 带有已生成的原页，关闭应用后仍可离线阅读。显示图像不表示已核实图中含义。
PPTX 可读取文字、明确上下标及结构线索，但完整页面图像仍依赖外部渲染工具。
桌面预览不自带 LibreOffice；也可先把 PPT 另存为 PDF。预览数量限制和缺页会在材料结果中说明。

这份本机构建为 **Apple 芯片、macOS 26.0+**，实测系统为 macOS 26.5.1。
其他构建的真实最低版本写在 `Contents/Resources/build-info.json` 中，不能仅凭原生外壳的编译目标推断兼容范围。
Windows、Linux、Intel Mac 和其他 macOS 版本尚未完成本地验收。

预览包只有 ad-hoc 签名，没有 Developer ID 签名和 Apple 公证。从网络下载时，macOS 可能阻止打开。
这是正式发行前仍待解决的门槛；项目不要求学生关闭 Gatekeeper 或系统安全设置。
GitHub Actions 构建产物用于开发验证，不等同于面向所有学生的正式安装包。

## 课程保存在哪里

课程、原材料副本、生成记录和学习记录放在系统的 Application Support 下的
`Multimodal Study Tutor` 目录。可从菜单「文件 → 在访达查看课程数据」打开。
它不在 `.app` 内，替换或移动应用不会删除课程。移除应用本身也不会删除这些数据。
多门课的历史文件仍保留，当前首页恢复最近保存的讲义；课程库切换界面仍待完善。

旧版 `start-study.command` 使用仓库内的 `local-data/my-study`，桌面应用不会搜索、移动或删除它。
需要迁移旧工作区时，先退出两个入口，再把旧工作区的**内容**拷入一个空的桌面数据目录。
不要把两个非空工作区直接合并。也可先导出讲义文件，在应用右上角选择「打开讲义」阅读。

正常退出前，应用等待最新答案和阅读位置保存到本机。保存冲突或失败会提示返回学习；
正在生成时会让你选择继续生成或退出。退出会中断生成，材料与上一份讲义保留。
下次打开不会自动续发模型请求，重试需要重新选择设置并同意。
强制退出或断电仍可能丢失最后尚未写入的修改；本机保存不等于备份。

## 开发者构建与检查

需要 macOS、Xcode Command Line Tools 和仅用于构建的 Python。学生运行产物不需要这些开发工具。

```bash
python3 -m venv /tmp/mst-desktop-build
/tmp/mst-desktop-build/bin/python -m pip install -r desktop/requirements-build.txt
/tmp/mst-desktop-build/bin/python desktop/build_macos.py --output dist/macos-preview
/tmp/mst-desktop-build/bin/python desktop/check_macos.py 'dist/macos-preview/听课助手.app' --output dist/desktop-check
```

输出目录必须是新目录，构建器不会删除上一次产物。构建器从运行环境的 Mach-O 文件读取最低系统要求，
把原生外壳、后端、网页、PDF 读取/渲染器、HTTPS 根证书及许可证装入应用，校验签名后生成 ZIP 和 SHA-256。
只收集明确的源码与资源，不打包课程目录、开发环境变量或模型密钥。
修改解释器或运行库时需复核 `desktop/licenses` 与最终第三方声明；当前构建不提供可重现二进制的承诺。

`check_macos.py` 在真实 WKWebView 中导入合成 Markdown/PDF，检查实际 PDF 文字、原页解码显示、HTML 内嵌原页、生成结果、三种导出、
作答和完成标记；通过原生下载委托导出并重复覆盖同一个 Markdown 文件。
退出后换一个应用路径重开，检查答案、阅读位置、完成标记和课程身份；
退出后后端必须结束。测试使用独立工作区，应用 PATH 中只有系统工具，不使用系统 Python 启动后端。
另用本机合成转写服务检查原生页面中的录音确认、实际字节上传、时间戳、密钥清空；
重开后选择本机模式重新生成，已有转写必须保留，服务总请求数仍为一次。
冻结运行时、PDF 读取器、有效根证书和 TLS 验证开关也会检查；测试不连接云端模型。
截图和报告只含合成材料。

自动检查没有操作系统文件选择框或下载保存框；这两项原生交互、网络下载后的 Gatekeeper 行为、
其他系统版本、正式签名/公证、专家审阅和学生盲测仍需要独立验收。
