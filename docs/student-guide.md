# 学生讲义层

使用独立 macOS 应用时，双击即可进入相同的学习页面，不需要 Python 或命令行；
使用方法、课程保存位置和兼容范围见 [桌面预览](desktop-preview.md)。

`lesson-map.json` 是后台的来源和证据地图，面向开发和验证；`study-guide.json`
是学生真正阅读的学习层。两者通过 `unit_id`、页面 ID 和时间片段 ID 连接，但学生正文不需要理解这些内部 ID。

## 学生阅读顺序

1. 先看本节要解决的问题、学习目标、先修知识和主线。
2. 进入知识单元，先用 30 秒预测，再看材料和教师补充。
3. 读导师补链，确认从条件到结果的每一步。
4. 读一个有具体条件、过程和结果的完整例题，再看只改变一个条件的变式。
5. 先独立完成回忆题、过程题和迁移题，再展开答案和解析。
6. 课末按主线闭卷复述，并从答案回跳到对应知识单元；阅读位置和练习草稿会自动保存。

“下一知识点”只负责翻页，完成状态需要自己标记，也可以撤销。重新打开网页会恢复阅读位置；
回到学习路线后也可以点“继续上次学习”。草稿先保存在浏览器，本地服务可用时也保存到课程工作区。
单元内容改变时，对应旧记录会失效；多窗口同时修改出现冲突时，会提示并保留本页浏览器草稿。
具体恢复范围见 [本地网页工作流](local-web.md)。

材料不完整时，点击草稿提示中的“查看材料处理结果”。网页会逐文件说明缺什么；
可以保留已上传的课件、只补交教师转写，或取消勾选坏文件再添加新版。
新一轮生成失败时旧讲义仍可阅读。读取到文字不等于已经讲透，补材料后仍有缺口的内容会继续标为草稿。

只有录音而没有教师转写时，添加录音后展开“录音怎么处理？”，选择“转写所选录音”。
核对录音列表、服务地址并输入转写密钥，单独勾选同意后生成；课件不会随录音发给转写服务。
默认使用请求分段时间的模型，其他服务或模型可在“调整转写服务或模型”中填写。
不想上传时保持“只用本机已保存的转写”，或添加 SRT/VTT、DOCX、TXT。
转写只解决录音变文字，具体解释仍由下方的讲解方式决定；结果仍需核对。

想进一步展开解释和例题，可以在网页选“模型讲解”，填入所选服务的模型名称和 API 密钥，
核对文件与发送地址后确认。每次生成都重新确认，密钥不保存；服务可能收费。
模型生成后也可能仍是草稿，尤其是图示、语音配对或知识依赖尚未核实时。

如果某个知识点用到前面的概念，页面会提供“卡住时返回”的链接；有课程规划时，也会说明这里为什么需要它。课前先修知识与课内基础单元分开展示，不要求你在开始前就会整节课的内容。

每个核心知识单元必须有可观察的学习动作、至少三步逻辑链、具体例题、变式、易错对照、回忆/过程/迁移三类练习、答案解析和可定位来源。缺少这些内容时，验证器会把讲义标为草稿或报告错误。

若看到“材料已整理，精讲待补充”，这一单元只有材料，尚未生成具体讲解。页面保留完整文字、可用的原页和已配准的教师补充，不再列出套话例题、通用答案或完成按钮。可从“补充材料或选择讲解方式”继续补交同课转写，或主动选择模型生成；补充后仍需核对。Markdown 和 HTML 导出也保留这个状态。课程中已有的具体例题和练习仍可正常学习，只有真实生成的练习才进入课后复习。

计算机系统课程的离线生成器会从材料中提取可确认的具体例子，例如 RISC-V 指令执行、二进制/十六进制转换和二进制加减法。它只在页面文字提供足够条件时生成完整答案；图表、公式或扫描页仍会标为待复核。
明确的数制转换也可在数学等其他学科中生成解析，不必为此改选计算机系统。

数制转换会保留原题数字，展示位权、余数和小数乘法的实际过程，再给出有确定答案的变式。
循环小数会标出循环节。材料答案与计算不一致时，两种结果都会保留并显示“待确认”；
无法明确识别的补码、位宽和多题混杂材料不会被强行套成普通进制转换。
常见的 `(1101)2`、全角括号和带负号的 `0b`/`0x` 写法可以读取；例如 `−101` 的负号会保留。
包含未识别运算或多个题目的文字会继续待确认，不会只取其中一个数来作答。

明确的普通二进制加减法会从最右位逐列讲解，写清每一列怎样算、本位写什么、为何进位或借位。
练习先检查位权规则，再补一个具体列的计算，最后把第一个数增加一后独立重算。
例如 `10000−00001` 的连续借位会逐列展开，帮助区分“右列已经借走的要减掉”和“向左列新借来的相当于本列的二”。
当前不把固定字长、补码或负差强行当成这种普通整数题；原数不超过 16 位。
已有讲解但尚未生成具体题目的单元，会说明练习待补充，不再要求你回答空泛的通用问题。

来源与状态中的“页面文字覆盖”只表示文字已读出；“需要视觉复核”表示页面包含图片、连接线、公式或其他文字抽取不能完全表达的结构。课堂语音会按定义、推导、例题、纠错、课堂强调和评价提示分类。不能确定课次或页面的片段显示为“语音配对待确认”，不会写入本课教师讲解；只有明确登记的补充才显示为“课堂补充”。课堂事务、导出标题和无内容的时间标记单独统计。

DOCX 可以把时间标记单独放在一段，程序会与后续讲话合并。下一个时间标记只能帮助划分段落，不能证明上一句恰好在该时刻说完；没有真实结束时间时，讲义显示“某时刻起”，不编造精确区间。

教师补充有对应的本机录音时，点“听这一段”就能回听所标时间段，支持倍速和重听；
有明确结束时间时会自动暂停。关闭回听继续看当前段落，作答不会丢失；切换知识点会停止播放。
回听只读取已导入的录音，不请求转写服务，不会因此上传材料或再次转写。
尚未配对的片段只在来源附录中提供回听，并继续标为待确认。
只有转写、没有录音，或没有真实起始时间时，不显示播放按钮；不会按相似文件名猜录音。
录音被替换或无法播放时，可以继续读讲义，核对后重新导入录音。
下载的 Markdown、HTML 和 JSON 不附带原录音；回听需在本地应用中打开原课程。

Markdown 和 HTML 导出的末尾也有默认折叠的来源索引，可以查看尚未配准的转写。HTML 复习题展开答案后，可以回到对应讲解。

有原页预览时，讲解的“材料中看什么”下面可以直接翻看课件；点“放大本页”核对箭头、公式、代码排版和图中标签。
原页默认展开，需要专心阅读时可以收起。图像较慢加载时，预览区会保留位置。
材料读取失败时，也可展开该文件的处理结果查看已经生成的原页；上一份讲义继续保留。

下载 HTML 会把已生成的原页一起保存，关闭应用或移动文件后仍能阅读。同一页只打包一次，后续引用提供回跳。
超出大小限制或缺少图像时会明确提示；Markdown 和 JSON 只保留图像引用，单独发送文件不附带原页。
PDF 预览由桌面应用内置；PPT 原页仍需本机 LibreOffice，或先将课件另存为 PDF。
扫描件可预览但不会自动变成文字或完整课程。视觉模型的结构观察也仍需复核。

## 状态与模型

`study generate` 默认不调用云端模型，只能生成保守的可追溯草稿。报告中的 `status: draft`
表示仍需模型或人工复核；它不会被界面显示成“已完成课程”。使用 `--provider openai`
后，模型可以补充直白解释、完整例题、易错点和练习，但来源页码、教师原话和评价承诺仍必须来自输入材料。

如果还没有知识地图，明确选择文本模型后，会先规划整节课，再按先修关系展开讲解；跨页出现的同一知识点可以合并。模型提出的学习顺序保留为导师建议，仍需复核。没有模型时，只合并原材料中明确的同标题页；主题较多而主线未重建时，页面会直接说明“学习主线待梳理”。不会用一长串幻灯片标题冒充学习路线。

三句重复步骤、同一道题换题型标签、解析照抄答案等内容不能通过严格检查，但检查通过也不等于所有推理或答案已被专家核验。来源附录会说明尚未讲解的材料及原因，帮助判断讲义哪里还不能单独用于学习。

原始音频可以通过 `--speech-provider openai` 显式请求转写，默认使用 `whisper-1` 请求分段时间戳；已有 VTT、SRT 或带时间标记的 DOCX 会直接进入对齐流程。主动指定 `gpt-4o-transcribe` 等模型时按 JSON 请求，未提供时间戳的文字仍保留，并明确提示无法精确定位录音，不制造时间戳。`gpt-4o-transcribe-diarize` 使用分说话人格式与自动分段，只有实际返回的时间和说话人会进入来源。

本工具当前每段录音的转写上传上限为 24 MB，不代表所有服务的统一上限。整批录音会在首次上传前检查；超限时请压缩或分段后重新导入，也可添加对应的 SRT/VTT。一次服务错误不会自动重发录音；错误信息说明下一步操作，不展示密钥或服务原始报错。

多份录音的片段分别记录，即使转写服务每份都从第一段开始编号，也不会互相覆盖。
同一项目、同一服务和模型下，已成功的录音会复用本地转写，不重复上传；后面的录音失败，重试会保留前面已完成的结果。
这是逐份录音恢复，单份录音在服务中途失败仍需重新处理。网页可显式选择转写，默认不上传。
补交材料会继承勾选保留录音的已完成转写，即使文件顺序改变也会重新对应来源；未勾选录音的转写不加入本次讲义。
重试时可以重新确认转写服务，只发送未完成的录音；也可改为只用本机转写，先保留已成功部分并明确报告其余缺口。
若本机同一录音存在不同版本的转写，需要选择原服务和模型确定来源，不会擅自拼接或再次上传。
录音在导入后被替换会先提示重新导入；已有转写和来源不会被静默覆盖。
确实需要再次调用转写服务时，命令行可加 `--refresh-transcription`；若新内容或时间与旧来源冲突，会停止并保留原记录，需核对或另建项目。
自动转写结果不等于教师内容和页面配对已经人工复核。云端转写仍需你主动选择，尚未完成真实服务验收。

原始课程文件不会被复制到公开仓库。使用云端 provider 前，应确认自己同意上传所选材料。
